## Избранные проекты

### 1. Olist Marketplace Analytics | PostgreSQL, SQL, Power BI

End-to-end проект по анализу данных e-commerce marketplace.

Проект охватывает полный путь данных: от загрузки исходных CSV-файлов в PostgreSQL до формирования очищенных данных, аналитических витрин и отчёта в Power BI.

Что сделано:

- загрузка исходных CSV-файлов в PostgreSQL;
- создание raw layer;
- профилирование данных;
- проверки NULL, дубликатов, ключей и связей;
- проверки качества и целостности данных;
- формирование clean и rejected layers;
- создание аналитических витрин;
- построение fact/dimension модели;
- контроль grain и cardinality;
- аналитические SQL-запросы;
- подключение данных к Power BI;
- построение интерактивного отчёта;
- упаковка проекта на GitHub.

Проект демонстрирует работу с PostgreSQL, SQL, качеством данных, моделированием данных и построением аналитического слоя.

[Открыть проект](https://github.com/aleksandr-data/olist-marketplace-analytics-sql-powerbi)
